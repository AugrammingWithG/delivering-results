# delivering Results — website concept

A concept mockup by Cre8tive Sync for [delivering Results](https://deliveringresults.com.au/), built around one idea: **The Foundation Stone** — a 3D stone in raked gravel. Drag to rake the sand, click to set a stone, and scroll as the marketing noise is raked into clarity.

Single `index.html` + `assets/`. Three.js 0.169.0 and GSAP 3.13.0 from CDN. Works without WebGL and with reduced motion.
